# DOJE-CONCEPT-SHEET.md — 12 도제 비주얼 시스템

## 개요

조선왕조 개발실록 매니저 4인 휘하 도제 12명의 **픽셀 아트 통일 가이드**. 
기존 베이스 SVG(planner-dojeon 32×32)를 모형으로 하여 12개 도제 캐릭터를 체계적으로 분기 생성하는 문서.

단청도제(frontend-dancheong SVG 구현자)가 이 시트를 읽고 각 도제별 `.svg` 파일을 생성할 수 있도록 구조화함.

---

## 1. 베이스 구조 기준

### 캔버스 및 그리드
- **크기**: 32×32 픽셀 (정수 그리드)
- **이미지 렌더링**: `image-rendering: crispEdges` (안티알리아싱 금지)
- **구조**: 아래 영역 분할로 일관성 유지

### 영역 분할 (y축 기준)

| 영역 | y 범위 | 요소 | 설명 |
|---|---|---|---|
| **모자** | y=3~8 | hat | 직군·계급 표현 |
| **얼굴** | y=9~16 | face (눈·눈썹·입) | 표정 코드 |
| **목·깃** | y=17~18 | neck, collar | 관복 시작 |
| **관복** | y=19~28 | robe | 메인 색상 + 음영 + 흉배 |
| **신발** | y=29~31 | feet | 관복과 동일 계열 |

### x축 기준 도구 배치

| x 범위 | 설명 |
|---|---|
| x=0~2 | 좌측 여백 |
| x=3~4 | 좌 소매 끝 (도구 1) |
| x=5~27 | 관복 메인 영역 + 흉배 |
| x=28~29 | 우 소매 끝 (도구 2) |
| x=30~31 | 우측 여백 |

## 2. 안 1 — 모자 분류 체계 (직군별 4분기)

매니저 계급 표현 다음으로, 도제의 직군(文·技·軍·學)을 모자 형태로 시각화.

### 2.1 문관계 (정도전 휘하) — **복두 (2단 전립)**

**특징**: 사모보다 낮고 납작함. 좌우 각이 짧거나 없음.

**픽셀 규칙**:
- 상단 모자: y=3~6 범위, x=8~24 영역 (16px 폭)
- 좌각 1px, 우각 1px (또는 각 제거)
- y=3~4: 상단 수평선 (계급 표시)
- y=5~6: 좌우 각 각 1px로 축소 또는 제거
- 목에 연결되는 부분: y=7~8에서 x=10~22로 좁혀듦

**포함 도제**: planning-hojo, docs-sagwan

### 2.2 기술계 (장영실 휘하) — **패랭이 / 공장건 (평민 모자)**

**특징**: 챙이 넓은 평민 모자. 가로 픽셀이 관복 밖으로 약간 삐져나감.

**픽셀 규칙**:
- y=3~5: 챙 부분, x=7~25 (18px 폭) — 관복보다 좌우로 1~2px 확장
- y=6~8: 모자 몸통, x=9~23
- 챙 끝이 약간 처진 형태 가능 (y=5에서 x=7, y=6에서 x=8 같은 사다리꼴)

**포함 도제**: frontend-dancheong, infra-tomok, integration-tongsin

**특수**: backend-gigwan은 공장건으로 챙을 더 좁게 (x=9~23만)

### 2.3 군계 (이순신 휘하) — **벙거지 / 전립 (무관 모자)**

**특징**: 낮고 둥근 형태. 위가 편평, 좌우 각 거의 없음.

**픽셀 규칙**:
- y=4~7 범위, x=9~23 (거의 관복 폭과 동일)
- y=4~5: 상단 수평선 (편평)
- y=6~7: 좌우 곡선 (각도 거의 0)
- 목에 자연스럽게 연결

**포함 도제**: security-chukhu, perf-uiwon, test-gungwan

### 2.4 학자계 (정약용 휘하) — **정자관 / 망건 (격자 관)**

**특징**: 얇은 망건 띠 + 위가 격자로 뚫린 관. 상단 여백에 격자 패턴 2~3px.

**픽셀 규칙**:
- y=3~4: 망건 띠 (검정 수평선 1px)
- y=5~7: 격자 관 (상단 영역 격자 무늬)
  - 격자: x 방향 2~3px 간격으로 세로 선
  - 2px 사각형 칸 1개 정도 패턴
- y=8: 관 하단 테두리

**포함 도제**: research-jeja, visual-hwagong

## 4. 안 3 — 흉배 등급 체계 (3단계)

### 4.1 레벨 정의

#### **레벨 0** — 흉배 없음 (군계 도제 일부, 정찰/훈련 역할)
- 신체: 관복 여밈선만 (검정 세로선 1px, x=16)
- 흉배: 미표시
- 포함: security-chukhu, test-gungwan (군계 전투 지향 도제)

#### **레벨 1** — 흉배 테두리만 (기술계 도제)
- 신체: 관복 여밈선 1px (검정)
- 흉배: **테두리만 1px 선으로 그린 빈 칸**
  - 크기: 2×2px 정사각형
  - 위치: x=15~17, y=22~24 (관복 상단)
  - 색상: 관복 음영 색상으로 테두리만
- 포함: frontend-dancheong, backend-gigwan, infra-tomok, integration-tongsin

#### **레벨 2** — 흉배 있음 (문관·학자계 도제)
- 신체: 관복 여밈선 1px (검정)
- 흉배: **내부 채움 있음, 매니저보다 1개 픽셀 작음**
  - 크기: 매니저 2×2px 대비 **1px 점만** (또는 2×1px)
  - 위치: x=15~17, y=22~24 (관복 상단)
  - 색상: 관복 메인 hex와 대비 색상 (예: 파란 관복 → 금색 1px 점)
- 포함: planning-hojo, uiux-hwawon, docs-sagwan, perf-uiwon, research-jeja, visual-hwagong

### 4.2 시각적 차이

```
레벨 0 (흉배 없음):
  관복 (y=19~28)
  여밈선만 (x=16)

레벨 1 (테두리만):
  ##
  ##  (2×2px 빈 사각형 테두리)

레벨 2 (채움 있음):
  ●   (1px 대조색 점 또는 2×1px 채움)
```

## 6. 안 5 — 표정 코드 (5가지 타입)

각 도제의 기질·직무를 눈·눈썹·입 조합으로 표현.

### 6.1 표정 정의

#### **집중형** — 눈썹 강조, 입 없음 또는 일자
**정서**: 계획·분석·집중
**픽셀 규칙**:
- 눈: 1×2px (일반)
- 눈썹: 추가 1px 선 (눈 위 y=10)
- 입: 없음 또는 3×1px 일자선
- 포함: planning-hojo, docs-sagwan, backend-gigwan

#### **온화형** — 입 양 끝 올림 (미소), 눈 가늘게
**정서**: 조화·배려·안정
**픽셀 규칙**:
- 눈: 1×1px 작은 점 (가늘게)
- 눈썹: 일반 1px
- 입: U자 형태 (양 끝 1px 올림, 3×2px)
- 포함: perf-uiwon, research-jeja

#### **긴장형** — 눈 넓게, 입 좁게
**정서**: 경계·의심·결연
**픽셀 규칙**:
- 눈: 3×2px 넓게
- 눈썹: 1px (또는 조금 내려감)
- 입: 2×1px 좁은 사각 (또는 일자)
- 포함: security-chukhu, test-gungwan

#### **들뜬형** — 눈 위 하이라이트 + 입 열림
**정서**: 열정·흥분·창의
**픽셀 규칙**:
- 눈: 2×2px 기본 + 위에 1px 흰색 하이라이트 (y=9에서만)
- 눈썹: 1px (약간 올림)
- 입: 3×2px 열린 모양 (암색 또는 투명 배경)
- 포함: uiux-hwawon, frontend-dancheong, visual-hwagong

#### **차분형** — 눈 감음, 입 감정 없음
**정서**: 담당·확신·침착
**픽셀 규칙**:
- 눈: 1×1px 또는 닫힌 듯 (—)
- 눈썹: 1px (직선)
- 입: 3×1px 일자 (감정 중립)
- 포함: infra-tomok, integration-tongsin

### 6.2 표정 위치 (표준)

| 부위 | y 범위 | x 범위 | 크기 |
|---|---|---|---|
| 좌 눈 | y=11~12 | x=10~11 | 1×2px |
| 우 눈 | y=11~12 | x=19~20 | 1×2px |
| 눈썹 | y=10 | x=9~21 | 1px 수평선 |
| 입 | y=14~16 | x=12~19 | 3×2px or 3×1px |
| 하이라이트 | y=9 | x=11, x=20 | 1px 점 |

## 8. 단청도제(SVG 구현자) 작업 노트

### 8.1 베이스 SVG → 12분기 생성 프로세스

1. **기본값 설정**
   - `/public/characters/` 디렉터리에 12개 파일 생성
   - 각 파일명: `[name].svg` (예: `planning-hojo.svg`)
   - 32×32, `image-rendering: crispEdges`

2. **모자 분기** (안 1)
   - 직군 파악 (문관계/기술계/군계/학자계)
   - y=3~8 영역만 다시 그리기
   - 나머지 영역 (y=9~31)은 매니저 베이스 그대로 복사 가능

3. **색상 변경** (안 4)
   - `fill` 속성 메인 hex로 변경 (y=19~28 관복)
   - 음영 레이어 hex 변경
   - 신발 (y=29~31) 음영 hex로

4. **도구 추가** (안 2)
   - x=3~4, x=28~29 (y=24~26)에 도구 아이콘 `<rect>` / `<polygon>` 추가
   - 1~3px 크기, 검정 또는 메인 hex 대비색

5. **흉배 수정** (안 3)
   - 레벨 결정: 매니저 기준
   - 레벨 0: 여밈선만 (기존)
   - 레벨 1: 테두리 1px 사각 추가 (2×2px)
   - 레벨 2: 1px 점 또는 2×1px 채움 추가

6. **표정 변경** (안 5)
   - y=9~16 얼굴 영역 재구성
   - 표정 코드에 따라 눈·눈썹·입 변경
   - 나머지 헤더 영역 (y=3~8 모자) 재사용

### 8.2 검증 체크리스트

```
[ ] 32×32 캔버스 크기 확인
[ ] image-rendering: crispEdges 속성 확인
[ ] 모자 형태 + 색상 매트릭스 일치 확인
[ ] 도구 아이콘 좌/우 소매 위치 확인
[ ] 흉배 레벨 (0/1/2) 확인
[ ] 관복 메인 hex + 음영 hex 매칭 확인
[ ] 표정 (집중·온화·긴장·들뜬·차분) 코드 확인
[ ] 신발 음영색 확인
[ ] 전체 아웃라인 및 각진 픽셀 정렬 확인
```

### 8.3 재사용 가능한 부분

| 부분 | 베이스에서 복사 | 수정 필요 |
|---|---|---|
| 모자 (y=3~8) | X | 직군별 재설계 |
| 얼굴 (y=9~16) | X | 표정 코드별 변경 |
| 목·깃 (y=17~18) | O | 색상만 변경 가능 |
| 관복 (y=19~28) | O | 색상 + 흉배 + 도구 변경 |
| 신발 (y=29~31) | O | 음영색 변경 |

## 9. IP 안전 및 설계 원칙

### 9.1 조선 위인 존엄 유지

- **캐릭터화**: chibi 스타일 (귀여운 픽셀 아트)이지만 자세·표정은 **결연하고 차분**.
- **금지 사항**:
  - 슬랩스틱, 저급 장난 표현
  - 역사인물 비하 또는 정치 풍자
  - 위인 외형 과도한 왜곡

- **허용**:
  - 직무에 맞는 도구·복식 (역사적 근거)
  - 팀워크 표현 (조정의 협력)
  - 인스타 콘텐츠로의 확장 (교육적 맥락)

### 9.2 직급·직무 명확성

- 각 도제의 **모자·색·도구·표정**은 직무 정체성 강화
- 도제와 매니저 간의 **색상 명도 차이**로 계급 시각화
- 흉배 등급으로 **책임·권위** 표현

### 9.3 일관성 유지

- 32×32 픽셀 그리드는 *모든 도제에 동일*
- 색상표는 `/src/components/characters.ts` truth source
- 표정·모자·도구 변형은 **이 문서 범위 내에서만**
